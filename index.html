Personal Finance

Personal Finance is a private, single-user application designed to organize and analyze personal financial transactions.

Features

  • Import financial transaction notifications from Gmail.
  • Extract transaction details from supported email receipts.
  • Organize transactions and review transaction history.
  • Generate personal spending and financial statistics.

Google Account Access

The application uses Google OAuth to obtain permission to read Gmail messages for transaction processing. Gmail data is used solely for the application's personal finance functionality.

Availability

This application is developed for personal use and is not offered as a public service.
