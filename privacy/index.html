Privacy Policy

Last updated: October 10, 2026

1. Overview

Personal Finance is a private, single-user application developed to organize and analyze personal financial transactions.

2. Information Accessed

With Google OAuth authorization, Personal Finance accesses Gmail messages to identify financial transaction notifications and receipts.

Relevant information may include transaction dates, amounts, currencies, merchants, financial institutions, account references, and email metadata.

3. Use of Information

Gmail data is processed for the following purposes:

  • Identifying financial transaction notifications.
  • Extracting and matching transaction information.
  • Maintaining personal transaction records.
  • Generating financial summaries and statistics.

Google user data is not used for advertising, marketing, or training generalized AI models.

4. Data Storage and Security

The application stores financial records and authentication credentials in a private, access-controlled environment.

Access to the application and its stored data is restricted to the application owner.

5. Data Sharing

Google user data is not sold or shared with advertisers or data brokers.

Google user data is used only to provide the personal finance functionality described above.

6. Data Retention and Deletion

Financial records are retained for personal financial tracking until deleted by the application owner.

The application owner may delete locally stored records and authentication credentials.

7. Revoking Google Access

Google Account access can be revoked at any time through Google Account third-party connections .

Revoking access prevents further authorized Gmail access but does not automatically delete previously stored financial records.

8. Google API Services

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.

9. Contact

For privacy-related questions, contact the application developer using the support email listed on the Google OAuth consent screen.
